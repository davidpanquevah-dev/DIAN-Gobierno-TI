# Gobierno de TI - DIAN

Proyecto académico de diagnóstico y priorización de Gobierno de TI de la DIAN mediante un modelo de análisis basado en AHP-TOPSIS.

## Objetivo

Construir un modelo de priorización basado en datos para evaluar y ordenar capacidades e iniciativas de Gobierno de TI relacionadas con gestión de datos, interoperabilidad y arquitectura tecnológica.

## Organización

Dirección de Impuestos y Aduanas Nacionales (DIAN).

## Estructura del proyecto

- `data/raw`: fuentes de datos originales.
- `data/processed`: datos procesados.
- `notebooks`: análisis y experimentación.
- `src`: código fuente.
- `results`: resultados del análisis.
- `figures`: visualizaciones.
- `docs`: documentación del proyecto.

## Metodología

El proyecto contempla un enfoque cuantitativo, descriptivo y prescriptivo, utilizando AHP para la ponderación de criterios y TOPSIS para la priorización de alternativas.

## Criterios de priorización

- Alineación estratégica
- Impacto
- Riesgo
